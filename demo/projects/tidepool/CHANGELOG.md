# Changelog

## [Unreleased]

## [0.3.0] - 2026-09-18

### Added

- `tidepool stations` lists every station with its timezone.
- CSV errors name the file and line they came from.

## [0.2.0] - 2026-08-30

### Added

- `tidepool table <station> <date>` prints hourly heights for a day.

### Changed

- High and low water are refined to the minute instead of the six-minute search step.

## [0.1.0] - 2026-08-12

### Added

- `tidepool next <station>` with three stations and eight constituents.
